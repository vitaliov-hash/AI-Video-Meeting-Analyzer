# Правила разработки

- Сначала прочитать `TECHNICAL_SPEC.md`, `PROJECT_CONTEXT.md`, `ACCEPTANCE.md` и связанные prompts.
- Выполнять только DZ Light. Не добавлять облачный импорт, дедупликацию, публикацию или функции PRO/PRO+.
- Работать в ветке `feature/dz-light`; не публиковать код или материалы.
- Видео хранить вне проекта; локальные базы, модельные файлы, загрузки и секреты не коммитить.
- Не подменять распознавание или AI-анализ заглушкой. Ошибка должна быть явной и повторяемой.
- Не отправлять данные в AI API автоматически, если не задан ключ активного провайдера.
- Все результаты и сообщения сохранять/передавать как UTF-8; оригинальный язык речи не переводить.
- Изменения делать с учётом повторного использования `process_video()` будущим локальным или облачным источником, не реализуя источник из облака сейчас.
- После этапа обновлять `PROJECT_CONTEXT.md`; перед завершением сверяться с `ACCEPTANCE.md`.
- Local Quality Gate: lint, tests, typecheck (N/A для текущего Python без статической типизации), build/syntax, runtime smoke, AI evals, secrets scan и git diff/status. Платные API вызовы не запускать.
