# DZ Pro — пакет сдачи и статус проверки

**Статус функций DZ Pro: реализованы и ранее прошли локальный реальный Cloud E2E. Статус финальной сдачи: пока не готова к передаче.** Не подготовлено реальное видео/последовательность кадров полного Cloud E2E; права на прошлую запись и результат не подтверждены. Текущая visibility GitHub проверена через API и CLI как **Public**; владелец выбрал не менять visibility в этом цикле. История признана небезопасной для публичного раскрытия; см. итоговый риск ниже. Vercel Showcase проходит deployment check, но точный публичный URL нужно записать в handout.

## Дополнение Stage 4 — статический Showcase

Ветка Stage 4 добавляет статический режим показа с синтетическими RU/EN материалами. Он не обращается к FastAPI, `/api/meetings`, Faster-Whisper или DeepSeek. Исходная версия примера и редакторская версия подписаны отдельно; обе транскрипции и конспекты вымышлены. Защитные механизмы Teacher Preview реализованы локально в текущей feature branch, но режим не включён и не развёрнут.

Инструкция для передачи преподавателю: `TEACHER_HANDOUT.md`. Права на реальные учебные видео и их транскрипты не подтверждены, поэтому они не включены в Showcase, скриншоты и публичный пакет.

## Облачный источник

Для импорта выбран Google Drive. Требуется публичный URL отдельного файла MP4/WebM; приложение принимает стандартные share-ссылки `/file/d/FILE_ID/view`, без OAuth или доступа к Gmail.

Backend валидирует host, HTTPS, порт, DNS IP, редиректы, длительность и максимальный размер скачивания. По сигнатуре определяет MP4/WebM; HTML страницы входа/подтверждения не обходит. Источник, canonical share URL и текущий этап сохраняются в SQLite; дубли URL не запускают повторный pipeline. Ручная загрузка и Drive import используют один `process_video()`.

## Проверка публичного импорта

Живой E2E выполнил анонимное получение WebM 11,484,674 bytes, извлечение аудио, реальную транскрибацию Faster-Whisper `small` (4:02, язык `en`, p=.99, 3,325 символов) и ровно один реальный DeepSeek анализ (HTTP 200; usage 1,106 prompt + 282 completion = 1,388 tokens). Результат сохранён; перезагрузка страницы, список, открытие карточки и повтор ссылки подтвердили persistence/dedup без повторного AI вызова. Общее время — 632.19 s. Ссылка, Drive ID и содержание записи в пакет не включены.

Автоматическая проверка числовых утверждений нашла их в транскрипте, но строгая проверка пересечения значимых слов не прошла. Смысловая корректность требует ручной сверки по исходной записи; это ограничение не скрывается.

## Демонстрация

Достаточно одной записи длительностью 2–5 минут. Видео перед публикацией ссылки должно быть собственным или иметь согласие/разрешение на обработку и показ. В Google Drive задайте «Все, у кого есть ссылка» → «Читатель», скопируйте share URL. Вставьте в приложение, покажите стадии и результат, обновите страницу, затем вставьте ту же ссылку повторно и убедитесь, что открылась прежняя встреча.

Не загружайте несколько записей без необходимости. Для живой демонстрации используйте один короткий файл, на который есть разрешение на обработку и показ; реальные клипы с неподтверждёнными правами не публикуются.

## Финализация DZ Pro — подготовка выдачи

- Публичное раскрытие исходного репозитория: **NOT SAFE**. В достижимой Git-истории есть личные Git author identities (в отчёте не перечисляются). На момент проверки GitHub API и CLI независимо сообщили `Public`. После этого владелец ответил «2 / пока не менять»; visibility я не менял и других GitHub write действий не выполнял. Уже сделанные копии истории нельзя отозвать последующим переключением. Если преподавателю нужен публичный просмотр, безопасный вариант — отдельный очищенный submission-репозиторий с новой историей и только проверенными материалами.
- Локально обнаружены недостижимые Git-объекты, содержащие приватный Drive identifier; по проверке их SHA отсутствуют на GitHub и они не достижимы из опубликованных refs. Не запускайте `git gc`/prune до отдельного решения о сохранении локальных объектов.
- Доступные GitHub Actions логи проверены без выгрузки персональных значений; секретов/личных ссылок не обнаружено. У проверенных прошлых runs нет artifacts. В repository отслеживаются только synthetic Showcase data и синтетические скриншоты; реальные видео, результаты SQLite, ключи и модели не включены. Источники реального тестового видео имеют неподтверждённые права.
- Предыдущая инструкция про collaborator относится к private режиму и сейчас неприменима: текущий исходный repo виден как Public. Имя аккаунта преподавателя пока не предоставлено.
- Vercel Showcase остаётся статическим режимом без backend и платных AI вызовов. GitHub Vercel commit status на `main` — success; [deployment record](https://vercel.com/vitali7/ai-video-meeting-analyzer/B9fwJxhThQBua2XWTk4XMe1Vbey3) ведёт на private dashboard. Точный публичный frontend URL следует подтвердить у владельца и записать в `TEACHER_HANDOUT.md`.
- Teacher Preview guardrails подготовлены, но backend, Cloudflare tunnel и Vercel Preview не включались. Это кандидат на разовую демонстрацию за $0, но сетевой E2E и длительная обработка через туннель не подтверждены. Нет SLA; выключенный по умолчанию backend требует ручной активации после отдельного подтверждения и проверки прав на запись.
- Новые реальные AI вызовы не выполнялись. Публикационная запись экрана/снимки не подготовлены, потому что права на прежнее видео и его результат не подтверждены. Финальная сдача остаётся условно незавершённой до получения одного права-cleared демонстрационного источника/согласия и подготовки настоящего доказательства полного сценария.
- Stage 5 tests: **35 passed**, Ruff, compileall, JavaScript syntax, Showcase/Teacher harness, guarded frontend build checks and `git diff --check` passed. All API processing cases in tests use a mocked pipeline; no new DeepSeek call.

## Финальное доказательство для сдачи — 2026-11-07

- Видео: `Banking Committee Hearing - Illegal Foreclosures.webm`, Wikimedia Commons, Public Domain в США / PD-USGov. Скачанный из Google Drive WebM совпал с Commons по SHA-1 `83a304528c3fc4ebd4c2c3ea91d600c595bf6343` и размеру 11,484,674 байта. Отдельный нюанс: Commons marking не является заявлением о получении индивидуальных согласий; если курс требует их отдельно, решение остаётся за преподавателем.

После дедупликации одна встреча и один использованный слот из двух.

- Текущая usage/token-метрика DeepSeek не сохранена adapter-ом приложения; per-call token count не заявляется. Предыдущую метрику нельзя приписывать этому вызову.

Учительская инструкция отделяет статический Showcase от выключенного Teacher Preview.
