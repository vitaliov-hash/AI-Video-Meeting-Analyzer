# Инструкция для видеодемонстрации DZ Light и DZ Pro

Для показа сохранённого английского примера используйте отдельный редакторский материал `DEMO_SUMMARY_EN_REVIEWED.md`. Он явно отделён от неизменённого исходного AI-конспекта и отмечает спорные числа и исправление имени. План пока не развёрнутых режимов приведён в `DEMO_MODES.md`.

## Перед записью

1. Установить зависимости и настроить локальный `.env` по README. Для полного сценария нужен согласованный действующий `DEEPSEEK_API_KEY` (или настроенный OpenAI/Gemini provider). Ключ остаётся только локально.
2. Убедиться в правах/согласии на запись и демонстрацию выбранного видео. См. `MEDIA_LICENSE_NOTES.md`.
3. Запустить `python -m meeting_analyzer` и открыть `http://127.0.0.1:8000`.

## Основной сценарий

1. Выбрать русское видео Дмитрия Емца (`Интервью_с_Дмитрием_Емцом.webm`, 4:46). Оно остаётся во внешней папке с исходными записями.
2. Показать автоматический статус «Обрабатывается» и дождаться результата.
3. Показать язык `ru`, краткое содержание, решения, следующие задачи, открытые вопросы и расшифровку. Проверить, что отсутствующие данные указаны явно.
4. Обновить страницу и снова открыть ту же встречу из истории.
5. Дополнительно повторить прогон для английского видео (4:02) и показать, что текст остаётся английским.

Снимать только интерфейс и тестовый материал, который разрешено демонстрировать. До отдельного согласования не публиковать видео, скриншоты, транскрипты, Showcase, приложение или репозиторий публично.

## Дополнение для DZ Pro: импорт из Google Drive

1. Для приватной проверки используйте одну английскую запись WebM длительностью около 4 минут. Для публичной демонстрации используйте только собственное или явно разрешённое видео; права на имеющиеся учебные клипы пока не подтверждены.
2. Для отдельного файла установите общий доступ «Все, у кого есть ссылка» с ролью «Читатель». Не используйте закрытый файл или ссылку на папку.
3. Скопируйте ссылку вида `https://drive.google.com/file/d/FILE_ID/view` в поле «Добавить из облака».
4. Покажите историю: сначала «Получение файла», далее «Распознавание речи», затем «AI-анализ» и «Готово».
5. Откройте встречу, покажите источник «Из облака», конспект и раскрываемую транскрипцию. Обновите страницу и проверьте сохранённую запись.
6. Повторно вставьте ту же ссылку: приложение откроет существующую встречу и не запустит новый AI-анализ.

Если Google Drive требует вход или показывает страницу подтверждения вместо скачивания, интерфейс объяснит проблему и предложит обычную загрузку сохранённого файла.

## Текущий статус

Реальная RU/EN транскрибация Lite и полный живой cloud E2E для одной EN записи завершены; см. метрики и результат ручной проверки в `ACCEPTANCE.md`. Для показа использовать только материал, на который есть право. Новых платных запросов не запускать без отдельного согласования. Публичная запись экрана/видео не создана.
