## Настоящее доказательство Cloud E2E

Откройте папку `dist/DZ-Pro-Final-Submission`:

- `cloud-e2e-short.mp4` — 57,6 секунды, смонтированный из настоящего захвата; участок ожидания ускорен в 16 раз и явно помечен.
- `cloud-e2e-full-original.webm` — исходная запись экрана, 345,8 секунды; хранится без монтажа.
- `01-drive-input.png`–`07-duplicate.png` — фактические кадры ввода скрытой ссылки, реальных фаз, готового результата, перезагрузки и дубликата.
- `08-summary-fullpage.png` — сохранённый результат после повторного запуска локального backend; видны все четыре раздела конспекта и оставшийся лимит 1 из 2.
- `timing.json` — фактическое время, модель, язык, этапы, один вызов DeepSeek и проверка повторной ссылки.

Демонстрация записана 2026-11-07 из отдельной защищённой Teacher-базы, в которой не было пользовательской истории. Google Drive WebM скачан реально; Faster-Whisper `tiny/int8` определил английский язык и создал транскрипт 3 315 символов; DeepSeek выполнил один анализ. Результат пережил обновление страницы. Повтор ссылки открыл ту же встречу; в базе осталась одна встреча, использован один из двух слотов. Прогон занял 341,5 секунды от добавления ссылки до повтора.

Предыдущая попытка остановилась из-за нехватки памяти при `small`; она не дошла до DeepSeek. В финальном показе использован настоящий Faster-Whisper `tiny/int8` для надёжной работы на доступной памяти. Основная конфигурация приложения не изменена. Токены текущего DeepSeek вызова недоступны: приложение не сохраняет поле usage ответа API. Новых платных вызовов после этого не было.

## Воспроизведение

1. Клонировать GitHub репозиторий и установить зависимости по `README.md`.
2. Скопировать в Google Drive отдельный согласованный MP4/WebM; выставить «Все, у кого есть ссылка» → «Читатель».
3. Запустить локальное приложение; для компьютера с ограниченной памятью установить `WHISPER_MODEL=tiny`, `WHISPER_COMPUTE_TYPE=int8`.
4. Вставить URL отдельного файла в «Добавить из Google Drive» и дождаться результата.
5. Обновить страницу, открыть сохранённую встречу, повторить ту же ссылку и проверить, что новый анализ не выполняется.

Размер, длительность и SHA-1 скачанного Drive-файла совпали с оригиналом; подробности — `MEDIA_LICENSE_NOTES.md` и `ИСТОЧНИК_ВИДЕО.md` в папке сдачи.
