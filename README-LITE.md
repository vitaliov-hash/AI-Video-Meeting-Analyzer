# AI Video Meeting Analyzer — DZ Light

Локальное приложение для загрузки видео встреч MP4/WebM, транскрибации русской и английской речи и создания структурированного AI-конспекта. Видео обрабатывается локально и удаляется после обработки; текст конспекта отправляется выбранному AI-провайдеру. Вызовы провайдера могут тарифицироваться.

## Требования

- Python 3.11 или 3.12.
- Интернет для установки пакетов и первого скачивания модели Faster-Whisper.
- Ключ AI-провайдера для генерации конспекта (по умолчанию DeepSeek).

## Установка и запуск в Windows PowerShell

1. Откройте PowerShell в папке проекта.
2. Выполните `Set-ExecutionPolicy -Scope Process Bypass`, затем `./setup.ps1`.
3. Добавьте `DEEPSEEK_API_KEY` в локальный `.env` (или выберите другой provider и его ключ). Не отправляйте `.env`.
4. Запустите `./start.ps1` и откройте `http://127.0.0.1:8000`.
5. Загрузите видео MP4/WebM. История встреч и результаты хранятся локально в `data/meetings.sqlite3`.

Первый запуск обработки скачивает модель Faster-Whisper `small`; модель кэшируется локально. Для тестов установите `requirements-dev.txt` и выполните `python -m pytest -q -p no:cacheprovider`.

## AI-конспект

В `.env` можно задать `AI_PROVIDER=deepseek|openai|gemini` и соответствующие API key/model settings. Секреты остаются на сервере; приложение не раскрывает их в HTML.

Перед публичной демонстрацией видео и транскрипта подтвердите права и согласие участников. В архив не включены видео, локальная база, модели и ключи.
