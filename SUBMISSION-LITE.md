# Материалы сдачи DZ Light

Архив `AI-Video-Meeting-Analyzer-DZ-Light.zip` содержит локальную версию анализатора: ручную загрузку MP4/WebM, Faster-Whisper для транскрибации, AI-конспект, локальную SQLite-историю, тесты и инструкции. В архив не входят исходные видео, локальная база, модель Whisper, `.env`, API-ключи или виртуальное окружение.

## Запуск

1. Распакуйте архив и откройте PowerShell в папке проекта.
2. Выполните `Set-ExecutionPolicy -Scope Process Bypass`, затем `./setup.ps1`.
3. Добавьте ключ выбранного AI-провайдера в локальный `.env`.
4. Выполните `./start.ps1` и откройте `http://127.0.0.1:8000`.
5. Загрузите согласованное видео MP4/WebM. Приложение распознает речь, создаст структурированный конспект и сохранит встречу локально.

## Приёмка

Для Lite проверялись русская и английская записи. Известный Lite baseline: 11 тестов прошли; Ruff, Python compileall и проверка JavaScript прошли. Перед передачей используйте таблицу критериев в `ACCEPTANCE.md`. Видео и транскрипты остаются вне архива; перед публичным показом нужно подтвердить права и согласие участников.
