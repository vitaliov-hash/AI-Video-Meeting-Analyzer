# Примечания по правам на тестовые записи

Некоторые исходные видео для предыдущих локальных проверок находятся вне репозитория. Их происхождение, лицензии и согласие на публикацию не подтверждены. Поэтому записи, фрагменты, транскрипты, подробности содержания и скриншоты реальных результатов запрещено включать в публичный Showcase, Git, ZIP или демонстрационное видео до отдельной проверки прав.

Локальная синтетическая сборка использует только вымышленные данные из `static/demo-data.json`. Реальные тестовые видео, модели, SQLite и пользовательские ссылки остаются вне пакета сдачи.
