# Техническое задание — DZ Light

## Цель

Локальное одностраничное приложение принимает видео встречи MP4/WebM, извлекает аудио, автоматически распознаёт речь и создаёт структурированный конспект на языке оригинала.

## Пользователь и сценарий

Один локальный пользователь открывает страницу, выбирает один файл и автоматически получает результат. Из списка встреч можно выбрать завершённую запись и открыть транскрипт и четыре раздела конспекта. После перезагрузки страницы записи остаются доступными.

## Проверяемые требования

1. Принимаются MP4 и WebM с компьютера; анализ начинается автоматически после выбора.
2. Видеообработка извлекает аудио из фактического видеофайла.
3. Speech-to-Text интерфейс отделён от интерфейса summarizer; локальный Faster-Whisper обнаруживает язык и транскрибирует речь без перевода.
4. Конспект включает краткое содержание, решения, следующие задачи и открытые вопросы.
5. Отсутствующие решения/задачи/вопросы явно обозначаются; исполнители, сроки и факты не выводятся без подтверждения транскриптом.
6. Интерфейс показывает «Обрабатывается», «Готово» и «Ошибка», объясняет ошибку и позволяет повторить загрузку.
7. История хранит имя файла, дату, статус, транскрипт и конспект в локальной SQLite базе; исходные видео не сохраняются.
8. Обрабатывается не более одной встречи одновременно.
9. Интерфейс и персистентный слой сохраняют Unicode/кириллицу.
10. DeepSeek является провайдером по умолчанию; OpenAI и Gemini настраиваются переменными окружения без изменения orchestration логики.

## Данные

Meeting: `id`, `filename`, `added_at` (UTC ISO-8601), `status` (`processing|ready|error`), `language` (BCP-47/код модели), `transcript`, `summary` JSON с ключами `short_summary`, `decisions[]`, `next_tasks[]`, `open_questions[]`, `error`.

Вход: локальный файл MP4/WebM с аудио. Сырой файл используется во временном файле и удаляется после обработки. Выход хранится в `data/meetings.sqlite3`.

## Архитектура

- FastAPI локальный backend и статическая одностраничная UI.
- `process_video()` — общий orchestration entry point для файла, извлекает audio через ffmpeg из `imageio-ffmpeg`, вызывает независимый `SpeechToTextProvider`, затем `SummaryProvider`.
- Faster-Whisper (multilingual, по умолчанию `small`, CPU int8) — локальный STT и автоопределение языка. Модель скачивается при первом запуске.
- Суммаризатор через адаптеры DeepSeek/OpenAI (Chat Completions) и Gemini (generateContent). Секреты только в серверных env.
- SQLite хранит локальную историю, source, текущий phase и нормализованный URL облачного источника; временные файлы находятся в локальной директории данных.
- DZ Pro: импорт отдельных публичных Google Drive share links без OAuth. Скачивание ограничено размером, таймаутами и числом редиректов; каждый URL должен быть HTTPS на разрешённом Google домене и разрешаться только в публичные IP. MP4/WebM подтверждаются сигнатурой. Страница входа/подтверждения не обходится. После импорта запускается тот же `process_video()`.
- Уникальный индекс на нормализованный source URL предотвращает повторный AI-анализ одной ссылки. Ошибки импорта сохраняются в истории с рекомендацией ручной загрузки.

## Ограничения и безопасность

- Локальный single-user запуск на `127.0.0.1`. GitHub/Vercel не публикуются без отдельного подтверждения пользователя.
- Не загружать видео в GitHub, UI материалы, логи или БД.
- Размер загрузки ограничен настройкой `MAX_UPLOAD_MB`; один файл в очереди.
- Вызов AI требует конфигурированного API ключа и может иметь стоимость; никаких реальных вызовов в CI/при разработке.
- Поддержка дополнительных языков достигается заменой/настройкой мультиязычной Whisper модели.

## За пределами обязательной части DZ Pro
