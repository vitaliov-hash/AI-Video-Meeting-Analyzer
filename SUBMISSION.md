# Материалы сдачи DZ Pro

Архив `AI-Video-Meeting-Analyzer-DZ-Pro.zip` содержит исходный проект, автоматические тесты и документацию. В пакет не входят API-ключи, персональные ссылки Google Drive, видео, локальная база, кэш модели или виртуальное окружение.

## Локальный запуск

1. Распакуйте архив и откройте PowerShell в папке проекта.
2. Выполните `Set-ExecutionPolicy -Scope Process Bypass`, затем `./setup.ps1`.
3. Добавьте ключ выбранного AI-провайдера в локальный `.env`. Не отправляйте ключ преподавателю и не включайте его в архив.
4. Выполните `./start.ps1` и откройте `http://127.0.0.1:8000`.
5. Для DZ Pro вставьте публичную ссылку на отдельный файл MP4/WebM в Google Drive. Нужен доступ «Все, у кого есть ссылка» с ролью «Читатель». OAuth и доступ к Gmail не используются.

После импорта дождитесь обработки, откройте сохранённую встречу, обновите страницу и проверьте историю. Повторная ссылка должна открыть прежнюю встречу без повторного анализа. Один live E2E уже пройден: английский WebM скачан из Drive, обработан Faster-Whisper, summary получен одним согласованным DeepSeek-вызовом и сохранён; повторная ссылка использовала тот же результат. Полные метрики и ограничение автоматической проверки grounding записаны в `ACCEPTANCE.md`.

## Ограничение материалов

Тестовые записи не входят в архив. Перед демонстрацией убедитесь, что у вас есть право обрабатывать и показывать выбранное видео. Подробности запуска и демонстрации приведены в `README.md` и `DEMO_GUIDE.md`.

## Проверки

Последний локальный прогон в отдельном Python 3.12.14 окружении: **28 tests passed**; Ruff, `compileall`, JS syntax, Vercel frontend build и `git diff --check` прошли. Unit/API tests используют mocks для cloud pipeline и не выполняют платные AI-запросы. Отдельный live E2E использовал ровно один согласованный DeepSeek-вызов; сверка результата и известные ограничения записаны в `ACCEPTANCE.md`.
